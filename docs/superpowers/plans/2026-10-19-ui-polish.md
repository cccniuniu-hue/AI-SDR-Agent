# 工作台视觉优化

用户已选择米白背景、墨绿色重点色的浅色专业风格。

## 实施范围

1. 统一页面、侧栏、按钮、表单、标签与信息卡样式；紧凑标题和导航。
2. 输入区与操作说明在宽屏并排，窄屏自动纵向排列；保留输入内容和现有操作标签。
3. 完整展示企业名称；用分组卡片呈现客户资料、业务规模、需求与下一步行动，保留全部 15 字段 JSON。
4. 审核表单按主题分组，保持预览、确认、版本检查与 null 规则。
5. 动态 HTML 内容统一转义，样式文件随 Python 包分发。

## 验证与交付

- 运行现有测试和 Ruff 检查，并验证动态卡片中的特殊字符不会成为 HTML。
- 浏览器检查工作台、历史记录、长企业名称、证据、人工修正，以及窄屏布局。
- 保存新版页面截图，提交并推送现有开发分支。
- 不生成或更新视频；模型调用、企业核实和持久化逻辑不在本次修改范围内。
