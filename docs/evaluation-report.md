# 验收与真实评测报告

日期：2026-10-19。模型：`deepseek-flash`，thinking disabled，temperature 0。真实服务为用户配置的 DeepSeek 账户；测试密钥、数据库和原始服务日志不提交 Git。

## 结论

应用已完成文本分析、15 字段导出、企业来源核实、意向评分、单条/批量审核及持久化。119 项自动化测试通过；全新虚拟环境完成安装、无密钥双页面启动和同一套测试。真实浏览器完成高意向、低意向、未知意向分析、单条修改、批量审核与历史检查。

本次合成数据上的结果不能证明真实业务准确率。保留集上完整方案与直接 Prompt 基线均为 12/12 意向正确，没有测得意向优势；企业正例仅 1 条，企业指标不足以支持泛化结论。未审核的新错字、简称和加盟主体仍可能保留 null。

## 数据与方法

- 开发集 12 条、保留集 12 条；每集 high、medium、low、null 各 3 条，全部明确标记为合成文本，情景组不跨集。来源及标签见 [evaluation](../evaluation/README.md)。
- 同一模型分别运行完整工作流与直接输出 Lead 的基线；基线不联网，也没有本地证据校验。预期标签不进入任何模型请求。
- 第一次保留集运行发生在最终修复前，双方意向均 12/12 正确。随后开发集暴露“我叫陈经理”被提取为职位“经理”的问题，补充任职陈述校验及回归测试；两个集合使用新输出文件复跑。下表为最终复跑结果，**保留集此时属于回归集，不能继续当作未见数据的独立验证**。
- 第一次保留集运行与最终运行的评测代码指纹不同，期间补充了恢复运行指纹检查。各次运行独立保存，不拼接样本结果。真实模型有波动：第一次基线开发集为 11/12，最终为 10/12。
- 汇总和逐样本结果见 [reports](../evaluation/reports/)。仅复制合成样本预测和脱敏统计，绝不复制凭据或用户通话。

## 限制与下一步

1. 企业识别仍是网页证据核实，不是官方工商数据库。直接关系句式的保守校验会牺牲覆盖率；只有地区、行业一致的已审核别名可自动复用，加盟/独立主体语境阻断自动确认。无证据的新错字不能凭模糊相似度直接填写主体。
2. 事实校验只覆盖当前明确规则和可验证原句，不能证明所有自然语言语义均正确。复杂否定、混合主体或深层反讽仍需审核。模型对脱敏号码或非常见职位可能提取不完整。
3. 扩大企业正例、错字和简称的真实脱敏测试集，建立从未看过的新保留集，再比较准确率、覆盖率和人工处理时间。现有录音未转写，未当作测试数据使用。
4. 本地单用户工具，不具备生产级登录、权限、后台任务、数据保留政策和多人协作。默认仅监听127.0.0.1。网络使用统一180秒预算及单请求30秒连接/读写超时；已发出的网络请求可能在预算到期后才返回，后续步骤停止。
5. 质量分未经统计校准；真实服务版本、搜索内容、网络和调用成本会变化，复跑结果可能不同。macOS/Linux及Windows11未独立验收。
