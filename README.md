# AI SDR Agent

将销售电话沟通的转写文本整理为结构化销售线索，并通过人工审核修正不确定的结果。

这里的 SQL 指 Sales Qualified Lead（销售合格线索）。

## 已确认的项目范围

- 仅接收通话文本，不支持音频上传或语音转写。
- 不接入真实 CRM，输出符合字段规范的 JSON 线索。
- 以 GitHub 仓库和可复现的本地运行说明交付，当前不要求部署在线服务。
- 未提供、无法确认或无法可靠推断的字段统一使用 JSON `null`，不使用空字符串、`"未知"` 或虚构内容代替。
- 核心能力包括信息抽取、企业抬头还原、客户意向判断和低置信度结果的人工审核。

## 计划实现的工作流

通话文本输入 → 信息抽取 → 企业候选匹配与核实 → 意向判断 → 字段校验 → 结构化输出 → 人工审核与反馈。

- 企业识别：保留原始称呼，结合地区、行业及可核实来源匹配企业主体；证据不足时保留待审核状态。
- 意向判断：结合预算、时间、痛点、使用规模、主动行为与拒绝信号，输出等级和原文依据。
- 人工审核：展示原始对话和判断依据，支持修正企业名称、意向等级及批量订正，并保存修改记录。
- 质量控制：区分客户购买意向与结果置信度；对缺失信息、匹配歧义和判断冲突进行标记。

## 输出字段

以下为初始字段约定；未取得可靠值时统一使用 `null`。

| 字段 | 含义 | 有值时的类型或范围 |
| --- | --- | --- |
| `company_name` | 经核实的企业名称 | 字符串 |
| `industry` | 行业 | 字符串 |
| `area` | 地区 | 字符串 |
| `contact_name` | 联系人姓名或原始称呼 | 字符串 |
| `contact_title` | 已确认的职位 | 字符串 |
| `phone` | 原文提供的手机号 | 字符串，保留原始脱敏形式 |
| `intent_level` | 客户意向等级 | `high` / `medium` / `low` |
| `intent_reason` | 意向判断依据 | 字符串 |
| `demand_summary` | 客户需求摘要 | 字符串 |
| `mendian` | 门店数 | 非负整数 |
| `shejishi` | 设计师人数 | 非负整数 |
| `call_time` | 通话发生时间 | ISO 8601 字符串 |
| `next_action` | 建议下一步 | 字符串 |
| `confidence_score` | 结果置信度 | 0 到 1 的数值 |
| `need_human_review` | 是否需要人工审核 | 布尔值 |

缺失人数不等同于 `0`，未表达预算不等同于没有预算。无法判定意向时不强行归为低意向，应输出 `null` 并标记人工审核。通话时间应来自输入或可信元数据，不使用处理时间代替。

## 获取项目

需先安装 Git，并配置具有本仓库访问权限的 GitHub SSH 密钥。

```sh
git clone git@github.com:cccniuniu-hue/AI-SDR-Agent.git
cd AI-SDR-Agent
```

当前仓库尚无可运行程序。后续实现时将补充并验证 Python 版本、依赖安装、环境变量、启动命令、示例输入和验证步骤，以支持本地复现。
